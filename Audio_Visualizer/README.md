# Audio Visualizer
## What this board does
A USB-C Powered board that takes audio input, digitizes it over I2S and analyzes it on an ESP32-S3-WROOM-1-N8R8. Results show on an on-board OLED. Header pins are placed to allow the ESP32-S3 to connect to an external display through I2C.

## Why this board exists
Because its kewl. And wanted to learn DSP.
